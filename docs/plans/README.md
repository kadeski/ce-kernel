# Plans

Implementation plans for work in progress, one file per plan: `YYYY-MM-DD-short-title.md`.
A plan says how a piece of work will be done. Delete it when its issue closes: git history is
the archive, and `docs/DESIGN.md` describes the result.

What is planned is tracked as GitHub issues with the
[`roadmap` label](https://github.com/kadeski/ce-kernel/issues?q=label%3Aroadmap), not here.
